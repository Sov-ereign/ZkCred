Zero-Knowledge Architecture

How AegisID Works

Built on Midnight's Compact language — the privacy boundary is enforced by cryptography, not promises.

01

Private Input

Enter your credit score and income locally. This data is provided as a private witness — it never leaves your device.

02

ZK Proof Generation

The Compact circuit evaluates your eligibility inside a zero-knowledge circuit. The proof server generates a cryptographic proof locally.

03

Selective Disclosure

disclose(eligible) is called deliberately. Only the boolean result crosses the privacy boundary to the public ledger.

04

On-Chain Verification

The proof is submitted to Midnight Preprod. The blockchain confirms your eligibility. Your raw financial data stays invisible forever.

The Privacy Boundary

🔒

Private Witness

Never On-Chain
  • ● Credit Score — raw numeric value (e.g. 720)
  • ● Annual Income — exact dollar amount in cents
  • ● User Salt — 32-byte random commitment binding
  • ● Identity — no KYC, no linkable ID
// Compact witness declaration
witness getPrivateCreditScore(): Uint<32>;
witness getPrivateAnnualIncome(): Uint<64>;
witness getPrivateSalt(): Bytes<32>;

🌐

Public Ledger State

On-Chain
  • ● isEligible — boolean only (true/false)
  • ● minCreditScore — the threshold value
  • ● minAnnualIncome — the threshold value
  • ● verificationCount — total proof count

Developer Setup

Run It Locally

1

Install Prerequisites

# Node 22+
nvm install 22 && nvm use 22

# Compact compiler
npm install -g @midnight-ntwrk/compact-cli

# Verify
node --version  # v22.x.x
compact --version
2

Start Proof Server & Install

# Clone & install
git clone https://github.com/your/zkcred
cd zkcred && npm install

# Start Docker proof server
docker compose up -d

# Compile Compact contract
npm run compile
3

Test & Deploy

# Run test suite
npm test

# Deploy to Midnight Preprod
npm run deploy

# Open UI
open ui/index.html
